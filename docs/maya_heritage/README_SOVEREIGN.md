# Maya Sovereign Architecture

Welcome to the **Sovereign Architecture** of Maya. We have completely bypassed the facade of relying on `gcc`, intermediate C code generation, Python wrappers, or dynamically linking `libc`. Maya is now a true, raw, native language ecosystem.

## How It Works
The Maya Bootstrap Compiler (located in `src/` and written in C) parses Maya source files and **directly emits raw ELF64 executable bytes** to disk. It handles all ELF metadata, headers, program sections, and dynamically maps Maya syntax directly into `x86_64` machine instructions.

### Freestanding & Autonomous
The resulting binaries generated by Maya are completely freestanding. They do not depend on the C Standard Library (`libc`) or any external OS libraries. Instead, Maya directly speaks to the Linux Kernel using raw `syscall` instructions for everything from printing to standard output (`sys_write`), allocating heap memory (`sys_mmap`), and gracefully terminating processes (`sys_exit`).

### Infinity Syntax (Dynamic Grammar)
Maya supports `@infinity_rule`, a revolutionary compile-time macro engine that allows the language grammar to mutate itself. By declaring rules like `@infinity_rule "si" => "@if"`, the parser dynamically adjusts its own rule set to expand the language without recompiling the compiler.

## Building the Bootstrap Compiler
To compile the Maya compiler itself, simply run:
```bash
gcc -o bin/maya src/compiler.c src/parser.c src/emitter.c -Wall -O2
```
This generates the `bin/maya` executable. Note: This is the last time you will need GCC.

## Compiling Maya Code natively
Write your `.maya` scripts and feed them directly to the native compiler:
```bash
./bin/maya infinity.maya
chmod +x a.out
./a.out
```
The output `a.out` will be a completely pure, dynamically allocated, `ELF64` machine-code file that executes flawlessly on an AMD64 Linux machine.

Enjoy your absolute sovereignty over the machine!
