## ১. লিপির দর্শন ও চরম সার্বভৌমত্ব
লিপি (Lipi) বিশ্বের প্রথম দ্বিভাষিক, সম্পূর্ণ স্বনির্ভর (Self-Hosted Sovereign) এবং স্বাধীন সিস্টেমস প্রোগ্রামিং ভাষা। লিপি একই সাথে বাংলা এবং ইংরেজি উভয় ভাষার রূপতত্ত্বে সম্পূর্ণ সাবলীল। 

লিপির প্রধান ৩টি প্রযুক্তিগত স্তম্ভ:
1. **১০০% সার্বভৌম ও শূন্য নির্ভরতা (Zero Dependencies):** লিপি সংকলন বা পরিচালনার জন্য পাইথন (Python), গিসিসি (GCC), এলএলভিএম (LLVM) বা সি স্ট্যান্ডার্ড লাইব্রেরি (`libc` / `glibc` / `musl`)-এর কোনো প্রয়োজন নেই।
2. **ডিরেক্ট সিলিকন মেশিন কোড (Direct ELF64 Generation):** কম্পাইলারটি মেমরিতে সরাসরি বাইনারি কোড (Machine Opcodes) তৈরি করে স্বয়ংসম্পূর্ণ লিনাক্স ELF64 এক্সিকিউটেবল ফাইল লিখে ফেলে।
3. **দ্বিভাষিক অ্যাবস্ট্রাক্ট সিনট্যাক্স ট্রি (Bilingual AST Equivalence):** বাংলায় লিখিত কোড (`যদি`, `কাজ`, `গঠন`) এবং ইংরেজিতে লিখিত কোড (`if`, `fn`, `struct`) একই ধরনের অভ্যন্তরীণ নোড গঠন করে এবং অভিন্ন গতিতে এক্সিকিউট হয়।

## ২. টুলচেইন ইকোসিস্টেম ও কমান্ড নির্দেশিকা
লিপির সার্বভৌম টুলচেইন `bin/` ডিরেক্টরিতে প্রস্তুত থাকে:

| বাইনারি | কাজ ও বিবরণ |
|---|---|
| `bin/lipc` | সার্বজনীন লিপি কম্পাইলার CLI (সরাসরি ডিরেক্ট ELF64 মেশিন কোড সংকলন) |
| `bin/lipi` | লিপি নেটিভ এক্সিকিউটর ও স্ক্রিপ্ট রানার |
| `bin/lipipkg` | সার্বভৌম প্যাকেজ ম্যানেজার ও ডিপেন্ডেন্সি পরিচালক |
| `bin/lipirepl` | লাইভ সিপিইউ ও মেমরি পরিদর্শন সুবিধাযুক্ত ইন্টারেক্টিভ আরইপিএল শেল |
| `bin/lipidbg` | হার্ডওয়্যার রেজিস্টার ও ELF বাইনারি স্ট্রাকচার ডায়াগনস্টিক ডিবাগার |
| `bin/lipils` | এডিটর ইন্টিগ্রেশনের জন্য অফিশিয়াল ল্যাঙ্গুয়েজ সার্ভার প্রোটোকল (LSP) ইঞ্জিন |

### কমান্ড নির্দেশিকা:
```bash
# ১. স্ক্রিপ্ট তাৎক্ষণিক চালানো
./bin/lipi examples/01_hello_world/main.lp

# ২. সরাসরি মেশিন কোডে স্বাধীন ELF64 বাইনারি তৈরি (Zero GCC, Zero Libc)
./bin/lipc src/compiler/elf_emitter.lp tests/01_hello.lp build/hello_app
chmod +x build/hello_app
./build/hello_app

# ৩. ইন্টারেক্টিভ শেল চালু করা
./bin/lipirepl

# ৪. সিস্টেম বাইনারি ডায়াগনস্টিক ও ডিবাগ
./bin/lipidbg build/hello_app
```

## ৩. লিপির আধুনিক ২.০ সিনট্যাক্স
লিপি ২.০ সিনট্যাক্স অপ্রয়োজনীয় জটিলতা ও বন্ধনীমুক্ত। এখানে কোনো সেমিকোলন (`;`), কোঁকড়ানো বন্ধনী (`{}`), বা শর্ত/ফাংশন সংজ্ঞায় কোনো কোলন (`:`) নেই। ব্লকের ব্যাপ্তি নির্ধারণ করা হয় সরাসরি **ইনডেন্টেশন (Indentation)** দিয়ে।

### দ্বিভাষিক চলক ও সংখ্যামালা
লিপিতে খাঁটি বাংলা সংখ্যামালা (`০, ১, ২, ৩, ৪, ৫, ৬, ৭, ৮, ৯`) এবং রোমান সংখ্যামালা (`0-9`) প্রথম শ্রেণীর নাগরিক হিসেবে সমর্থিত:

```lipi
// বাংলা শৈলী
ধরি ভাষা = "লিপি ২.০"
ধরি সংস্করণ = ২
ধরি পাই = ৩.১৪১৫৯
ধরি সক্রিয় = সত্য

// ইংরেজি শৈলী
language = "Lipi 2.0"
version = 2
pi = 3.14159
is_active = true

বলো "স্বাগতম: " + ভাষা
say "Version: " + version
```

### শর্ত ও ব্রাঞ্চিং
শর্তের ক্ষেত্রে কোনো কোলন বা প্রথম বন্ধনীর বাধ্যবাধকতা নেই:

```lipi
// বাংলা সিনট্যাক্স
যদি বয়স >= ১৮
    বলো "প্রাপ্তবয়স্ক নাগরিক — ভোটাধিকার সক্রিয়"
নাহলে_যদি বয়স >= ১৩
    বলো "কিশোর নাগরিক"
নাহলে
    বলো "শিশু"

// ইংরেজি সিনট্যাক্স
if status == 200
    say "HTTP 200 OK: অনুরোধ সফল"
elif status == 404
    say "HTTP 404: রিসোর্স পাওয়া যায়নি"
else
    say "অন্যান্য অবস্থা: " + status
```

### লুপ ও পুনরাবৃত্তি
লিপিতে পুনরাবৃত্তির জন্য ৩টি আধুনিক কনস্ট্রাক্ট রয়েছে:
1. `যতক্ষণ` / `while` (শর্তভিত্তিক লুপ)
2. `প্রতিটি ... ভেতরে` / `for ... in` (রেঞ্জ ও উপাদান লুপ)
3. `N বার বলো` / `repeat N` (নির্দিষ্ট সংখ্যায় পুনরাবৃত্তি)

```lipi
// ১. রেঞ্জ লুপ
প্রতিটি i ভেতরে ১..৫
    বলো "কাউন্টার ধাপ: " + i

for count in 1..5
    say "English counter: " + count

// ২. নির্দিষ্ট বার পুনরাবৃত্তি
৩ বার বলো "সার্বভৌম লিপি ২.০!"

repeat 3
    say "Native execution without virtual machine"

// ৩. হোয়াইল লুপ
ধরি n = 5
যতক্ষণ n > 0
    বলো "গণনা: " + n
    n = n - 1
```

### ফাংশন ও কাজের সংজ্ঞা
ফাংশন সংজ্ঞায়িত করতে বাংলায় `কাজ` অথবা ইংরেজিতে `fn` ব্যবহৃত হয়:

```lipi
// বাংলা শৈলী
কাজ যোগফল(ক, খ)
    ধরি ফলাফল = ক + খ
    ফেরত ফলাফল

// ইংরেজি স্পেস-ডিলিমিটেড মিনিমাল শৈলী
fn multiply a b
    return a * b

বলো "যোগের উত্তর: " + যোগফল(১০, ২০)
say "Multiplication: " + multiply(6, 7)
```

### কাস্টম গঠন ও টাইপ
জটিল ডেটা স্ট্রাকচার গঠনের জন্য `গঠন` বা `struct` ব্যবহৃত হয়:

```lipi
// স্ট্রাকচার ঘোষণা
গঠন শিক্ষার্থী
    নাম
    রোল
    বিভাগ

// অবজেক্ট ইন্সট্যান্স তৈরি

শিক্ষার্থী১.নাম = "সাকিল আহমেদ"

শিক্ষার্থী১.বিভাগ = "কম্পিউটার বিজ্ঞান ও প্রকৌশল"

বলো শিক্ষার্থী১.নাম + " | রোল: " + শিক্ষার্থী১.রোল
```

## ৪. স্ট্রাক্ট মেথডস ও অবজেক্ট অরিয়েন্টেড প্রোগ্রামিং

লিপি ২.০ অবজেক্ট-অরিয়েন্টেড স্ট্রাক্ট মেথড (`fn Struct.method self arg1 arg2`) সরাসরি সমর্থন করে। এটি কম্পাইল-টাইমে জিরো-কস্ট স্ট্যাটিক ডিসপ্যাচে অনূদিত হয়।

### ৪.১ মেথড ডিক্লারেশন ও বাস্তবায়ন
স্ট্রাক্ট ডিক্লেয়ার করার পর ডট নোটেশন দিয়ে সরাসরি মেথড যুক্ত করা যায়:

```lipi
struct Point
    x
    y

// মেথড সংজ্ঞা: self প্রথম প্যারামিটার হিসেবে ইন্সট্যান্স পয়েন্টার গ্রহণ করে
fn Point.set_xy self new_x new_y
    self.x = new_x
    self.y = new_y
    return self

fn Point.distance_sq self other
    dx = self.x - other.x
    dy = self.y - other.y
    return (dx * dx) + (dy * dy)

// ব্যবহার পদ্ধতি
p1 = Point()
p1.set_xy(10, 20)

p2 = Point()
p2.set_xy(13, 24)

dist = p1.distance_sq(p2)
say "বিন্দুদ্বয়ের দূরত্বের বর্গ: " + dist
```

বাংলায় স্ট্রাক্ট মেথডের ব্যবহার:
```lipi
গঠন আয়তক্ষেত্র
    দৈর্ঘ্য
    প্রস্থ

কাজ আয়তক্ষেত্র.সেট self l w
    self.দৈর্ঘ্য = l
    self.প্রস্থ = w
    ফেরত self

কাজ আয়তক্ষেত্র.ক্ষেত্রফল self
    ফেরত self.দৈর্ঘ্য * self.প্রস্থ

ধরি জমি = আয়তক্ষেত্র()
জমি.সেট(২০, ১০)
বলো "জমির মোট ক্ষেত্রফল: " + জমি.ক্ষেত্রফল()
```

### ৪.২ রেজিস্টার পাসিং ও হার্ডওয়্যার ABI
কম্পাইলার যখন `p1.set_xy(10, 20)` কল সনাক্ত করে:
1. ভ্যারিয়েবলের স্ট্রাক্ট টাইপ নির্ণয় করে সিম্বলটিকে `lipi_fn_Point_set_xy` নামে রূপান্তর করে।
2. **AMD64 (x86_64) রেজিস্টার রুল:**
   - প্রথম আর্গুমেন্ট `self` পয়েন্টার চলে যায় রেজিস্টার `%rdi`-তে।
   - দ্বিতীয় আর্গুমেন্ট `new_x` চলে যায় `%rsi`-তে।
   - তৃতীয় আর্গুমেন্ট `new_y` চলে যায় `%rdx`-তে।
   - চতুর্থ থেকে ষষ্ঠ আর্গুমেন্ট `%rcx`, `%r8`, `%r9`-তে নির্ধারিত হয়।
3. **AArch64 (ARM64) রেজিস্টার রুল:**
   - `self` পয়েন্টার চলে যায় রেজিস্টার `X0`-তে।
   - পরবর্তী আর্গুমেন্টগুলো ক্রমানুসারে `X1`, `X2`, `X3` ইত্যাদি রেজিস্টারে পাস হয়।
4. কোনো ভার্চুয়াল মেথড টেবিল (vtable) বা ইনডাইরেকশনের প্রয়োজন হয় না; সরাসরি ১ সাইকেলে মেথড কল সম্পন্ন হয়।

### ৫.১ মাল্টিবুট ১ হেডার ও ওএস বুটস্ট্র্যাপিং
x86_64 বাইনারিগুলোর ১২৪ নম্বর বাইট অফসেটে একটি খাঁটি মাল্টিবুট ১ হেডার এমবেড করা থাকে:
- **ম্যাজিক নম্বর:** `0x1BADB002`
- **ফ্ল্যাগস:** `0x00000000`
- **চেকসাম:** `0xE4524FFE`

এর ফলে যেকোনো লিপি বাইনারি সরাসরি বাস্তব হার্ডওয়্যারে অথবা QEMU-তে অপারেটিং সিস্টেম ছাড়াই সরাসরি বুট করা সম্ভব:
```bash
qemu-system-x86_64 -kernel build/hello_app
```

### ৫.২ পিফোল মেশিন কোড অপ্টিমাইজেশন (Peephole 2-Byte XOR)
চলক শূন্যে ইনিশিয়ালাইজ করার ক্ষেত্রে ১০-বাইটের দীর্ঘ ইনস্ট্রাকশন (`movabsq $0, %rax`) ব্যবহার না করে লিপি ২-বাইটের অপকোড নির্গমন করে:
```asm
31 C0        ; xor %eax, %eax (সরাসরি %rax এর ওপরের ৩২-বিটসহ শূন্য করে দেয়)
```
- কোডের আকার ৮০% হ্রাস পায়।
- সিপিইউ পাইপলাইনে রেজিস্টার রিনেমিংয়ের সময় এটি ০-সাইকেলে এক্সিকিউট হয়।

## ৬. কনকারেন্সি, থ্রেডিং ও মেমরি মডেল

লিপি অপারেটিং সিস্টেম কার্নেল থ্রেড সরাসরি পরিচালনা করে `std/thread.lp`-এর মাধ্যমে। কোনো বাহ্যিক `pthreads` বা C লাইব্রেরি ছাড়াই মাল্টিপল সিপিইউ কোর ব্যবহার করা সম্ভব।

### ৬.১ লিনাক্স কার্নেল থ্রেড সৃষ্টি (`SYS_clone`)
নতুন থ্রেড তৈরি করার জন্য লিনাক্সের `SYS_clone` (সিসকল ৫৬ x86_64-এ, সিসকল ২২০ ARM64-এ) ডাকা হয়:

```lipi
include "std/thread.lp"
include "std/mem.lp"

// থ্রেডের জন্য নতুন স্ট্যাক তৈরি (৬৪ KB মেমরি পেজ)
ধরি স্ট্যাক_সাইজ = 65536
ধরি স্ট্যাক_মেমরি = syscall(9, 0, স্ট্যাক_সাইজ, 3, 34, -1, 0)
ধরি স্ট্যাক_টপ = স্ট্যাক_মেমরি + স্ট্যাক_সাইজ - 16

// থ্রেড সৃষ্টি (CLONE_VM | CLONE_FS | CLONE_FILES | CLONE_THREAD = 69376)
ধরি টিআইডি = থ্রেড_তৈরি(স্ট্যাক_টপ)

যদি টিআইডি == 0
    // এটি চাইল্ড থ্রেড
    বলো "চাইল্ড থ্রেড কাজ করছে নিজস্ব কোরে..."
    থ্রেড_প্রস্থান(0)
নাহলে
    // এটি মূল থ্রেড
    বলো "মূল থ্রেড: নতুন চাইল্ড থ্রেড আইডি = " + টিআইডি
```

### ৬.২ পরমাণু স্পিনলক (Atomic Spinlocks)
একাধিক থ্রেডের ভেতর ডেটা করাপশন রোধ করতে মেমরি লকিং মেকানিজম:
```lipi
// লক মেমরি বরাদ্দ
ধরি লক_মেম = malloc(8)
mem_write(লক_মেম, 0, 0) // আনলক অবস্থা

// ক্রিটিক্যাল সেকশনে প্রবেশের আগে লক নেওয়া
স্পিনলক_আটক(লক_মেম)

// নিরাপদ ডেটা আপডেট
শেয়ার্ড_কাউন্টার = শেয়ার্ড_কাউন্টার + ১

// ক্রিটিক্যাল সেকশন শেষে লক মুক্ত করা
স্পিনলক_মুক্ত(লক_মেম)
```
স্পিনলক আটকের সময় থ্রেডটি বিজি-লুপে সিপিইউ নষ্ট না করে `SYS_sched_yield` (সিসকল ২৪) কল করে অন্য থ্রেডকে সুযোগ দেয়।

### ৬.৩ বাম্প-পয়েন্টার অ্যারিনা মেমরি পুল (`std/arena.lp`)
ঘন ঘন `malloc`/`free` এর ফলে মেমরি ফ্র্যাগমেন্টেশন তৈরি হয়। লিপির `std/arena.lp` ও(১) কমপ্লেক্সিটিতে মেমরি বরাদ্দ ও তাৎক্ষণিক মুক্তি নিশ্চিত করে:
```lipi
include "std/arena.lp"

// ১ মেগাবাইটের অ্যারিনা মেমরি পুল তৈরি
পুল = অ্যারিনা_তৈরি(1048576)

// ৮-বাইট অ্যালাইন্ড মেমরি বরাদ্দ (O(1))
ব্লক১ = অ্যারিনা_বরাদ্দ(পুল, 128)
ব্লক২ = অ্যারিনা_বরাদ্দ(পুল, 1024)

// পুরো অ্যারিনা ০-সাইকেলে তাৎক্ষণিক রিসেট (জিরো মেমরি লিক)
অ্যারিনা_রিসেট(পুল)

// কাজ শেষে কার্নেলে মেমরি ফেরত দেওয়া
অ্যারিনা_ধ্বংস(পুল)
```

## ৭. নেটিভ ওয়েব রাউটার ও ব্যাকএন্ড (`std/web.lp`)

### ৭.১ ওয়েব ইঞ্জিন স্ট্রাকচার

- `WebRequest`: মেথড, পাথ, কোয়েরি স্ট্রিং এবং বডি ডেটার পার্সড অবজেক্ট।
- `WebResponse`: স্ট্যাটাস কোড, কনটেন্ট-টাইপ ও বডি সহ সম্পূর্ণ HTTP/1.1 রেসপন্স অবজেক্ট।

### ৭.২ পূর্ণাঙ্গ প্রোডাকশন মাইক্রোসার্ভিস উদাহরণ
```lipi
include "std/web.lp"

// ১. রাউটার তৈরি ও এন্ডপয়েন্ট নিবন্ধন
রাউটার = web_router_new()

web_get(রাউটার, "/", 1)
web_get(রাউটার, "/api/health", 2)
web_get(রাউটার, "/api/user", 3)
web_post(রাউটার, "/api/echo", 4)

// ২. ইনকামিং রিকোয়েস্ট হ্যান্ডলিং ও রেসপন্স প্রদান
কাজ হ্যান্ডেল_রিকোয়েস্ট(কাঁচা_রিকোয়েস্ট)
    ধরি মেথড = web_parse_method(কাঁচা_রিকোয়েস্ট)
    ধরি পাথ = web_parse_path(কাঁচা_রিকোয়েস্ট)
    ধরি হ্যান্ডলার_আইডি = web_dispatch(রাউটার, মেথড, পাথ)

    যদি হ্যান্ডলার_আইডি == 1
        ফেরত web_response_html("<h1>স্বাগতম লিপি ২.০ সার্বভৌম ওয়েব সার্ভারে!</h1>")

    যদি হ্যান্ডলার_আইডি == 2
        ফেরত web_response_json("{\"status\":\"ok\",\"uptime\":\"99.99%\"}")

    যদি হ্যান্ডলার_আইডি == 3
        ধরি নাম = web_parse_param_str(কাঁচা_রিকোয়েস্ট, "name=")
        যদি len(নাম) == 0
            নাম = "অতিথি"
        ফেরত web_response_json("{\"user\":\"" + নাম + "\",\"role\":\"engineer\"}")

    যদি হ্যান্ডলার_আইডি == 4
        ফেরত web_response_json("{\"message\":\"Data received successfully\"}")

    // রাউট না মিললে ৪০৪ রেসপন্স
    ফেরত web_response_not_found()

// ৩. ওয়্যার প্রোটোকল সিরিয়ালাইজেশন
ধরি রেসপন্স = হ্যান্ডেল_রিকোয়েস্ট("GET /api/health HTTP/1.1\r\n\r\n")
ধরি ওয়্যার_ডাটা = web_serialize_response(রেসপন্স)
বলো ওয়্যার_ডাটা
```

## ১০. ইন্টারেক্টিভ শেল ও সিস্টেম ডিবাগার (`lipirepl` ও `lipidbg`)

### ১০.১ লাইভ আরইপিএল শেল (`lipirepl`)
```bash
./bin/lipirepl
```
- `:eval <expr>`: তাৎক্ষণিক গাণিতিক এক্সপ্রেশন পরীক্ষা।
- `:reg` বা `:রেজিস্টার`: হার্ডওয়্যার স্ট্যাক পয়েন্টার (`%rsp`) এবং সিপিইউ ক্লক টাইমস্ট্যাম্প (RDTSC) ডাম্প।
- `:mem <addr> <len>`: মেমরির ঠিকানা সরাসরি বাইট-বাই-বাইট হেক্স ভিউতে প্রদর্শন।
- `:exit` বা `:বিদায়`: আরইপিএল বন্ধ করা।

### ১০.২ সার্বভৌম সিস্টেম ডিবাগার (`lipidbg`)
```bash
./bin/lipidbg build/hello_app
```
বাহ্যিক GDB ছাড়াই `lipidbg` সরাসরি:
- ELF64 ফাইল হেডার, প্রোগ্রাম হেডার ও এন্ট্রি পয়েন্ট যাচাই করে।
- ম্যাজিক বাইট (`0x7F 'E' 'L' 'F'`) ও ৬৪-বিট আর্কিটেকচার কনফার্ম করে।
- স্ট্যাক পয়েন্টার ও কোড বাউন্ডারির অখণ্ডতা ডায়াগনস্টিক করে।

## ১১. ভিজুয়াল স্টুডিও কোড (VS Code) ও LSP সেটআপ

লিপির অফিশিয়াল আধুনিক এডিটর টুলিং `editors/vscode/` অথবা `vscode-lipi/`-এ প্রস্তুত:
- সম্পূর্ণ বাংলা এবং ইংরেজি দ্বিভাষিক সিনট্যাক্স হাইলাইটিং (`lipi.tmLanguage.json`)।
- স্মার্ট ইনডেন্টেশন এবং ব্র্যাকেট রুলস (`language-configuration.json`)।
- বিল্ট-ইন ল্যাঙ্গুয়েজ সার্ভার প্রোটোকল (`bin/lipils`) সরাসরি কোড নেভিগেশন ও ডায়াগনস্টিক প্রদান করে।

### এক্সটেনশন ইনস্টলেশন:
```bash
# এক্সটেনশন সরাসরি লোকাল ডিরেক্টরিতে সেটআপ
mkdir -p ~/.vscode/extensions/lipi-lang-2.0.0
cp -r editors/vscode/* ~/.vscode/extensions/lipi-lang-2.0.0/
```
ভিএস কোড রিস্টার্ট করলেই যেকোনো `.lp` বা `.lipi` ফাইল ওপেন করলে পূর্ণাঙ্গ আধুনিক লিপি ২.০ ডেভেলপমেন্ট এনভায়রনমেন্ট সক্রিয় হয়ে যাবে।
