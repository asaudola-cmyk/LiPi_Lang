## ১. লিপির দর্শন ও চরম সার্বভৌমত্ব
লিপি (Lipi) বিশ্বের প্রথম বহুভাষিক, সম্পূর্ণ স্বনির্ভর (Self-Hosted Sovereign) প্রোগ্রামিং ভাষা যা একই সাথে বাংলা এবং ইংরেজি উভয় ভাষার রূপতত্ত্ব সমর্থন করে। 

লিপির প্রধান ৩টি স্তম্ভ:
1. **শূন্য নির্ভরতা (Zero Dependency):** লিপি চালানোর জন্য কোনো পাইথন (Python), গিসিসি (GCC), বা সি স্ট্যান্ডার্ড লাইব্রেরি (libc)-এর ওপর নির্ভর করতে হয় না। 
2. **ডিরেক্ট মেশিন কোড ইমিশন (Direct ELF Generation):** `src/compiler/elf_emitter.lp` সরাসরি লিপির সোর্স কোড থেকে লিনাক্স x86_64 বাইনারি এবং মাল্টিবুট ১ কার্নেল ইমেজ তৈরি করে।
3. **প্রাকৃতিক দ্বিভাষিক সিনট্যাক্স (Bilingual Syntax):** ডেভেলপার তার নিজস্ব মাতৃভাষা বাংলায় কোড লিখতে পারেন অথবা স্ট্যান্ডার্ড ইংরেজিতে কোড লিখতে পারেন। উভয় কোড একই অভ্যন্তরীণ মধ্যবর্তী উপস্থাপনা (AST) তৈরি করে।

## ২. টুলচেইন ইনস্টলেশন ও ওভারভিউ
লিপির প্রধান এক্সিকিউটেবল ফাইলগুলো `bin/` ডিরেক্টরিতে থাকে:

| বাইনারি | কাজ |
|---|---|
| `bin/lipc` | সার্বজনীন লিপি কম্পাইলার (C ট্রান্সপাইলেশন এবং সরাসরি ELF উভয় মোড সমর্থিত) |
| `bin/lipc_native_elf` | সরাসরি মেমোরিতে সি এবং সি লাইব্রেরি ছাড়া ELF জেনারেটর |
| `bin/lipi` | লিপি নেটিভ রানার ও ইন্টারেক্টিভ REPL |
| `bin/lipipkg` | ডিপেন্ডেন্সি ও প্যাকেজ ম্যানেজার |
| `bin/lipils` | ল্যাঙ্গুয়েজ সার্ভার প্রোটোকল (LSP) সার্ভার |
| `bin/lipidbg` | ইন্টারেক্টিভ সিস্টেম ও অ্যাসেম্বলি ডিবাগার |

### দ্রুত শুরু:
```bash
# সংস্করণ পরীক্ষা
./bin/lipi --version

# স্ক্রিপ্ট সরাসরি চালানো
./bin/lipi tests/01_hello.lp

# নেটিভ বাইনারি কম্পাইল করা
./bin/lipc tests/01_hello.lp -o hello_bin
./hello_bin

# শূন্য গিসিসি, সরাসরি মেশিন কোড কম্পাইল করা
./bin/lipc --direct-elf tests/01_hello.lp -o hello_elf
./hello_elf
```

## ৩. লিপির মৌলিক সিনট্যাক্স

### চলক ও ডেটা টাইপ
লিপিতে ডাইনামিক এবং স্ট্রং টাইপিং বিদ্যমান। বাংলায় `ধরি` বা `ধরো` কিওয়ার্ড এবং ইংরেজিতে সরাসরি অ্যাসাইনমেন্ট করা যায়:

```lipi
// বাংলা সিনট্যাক্স
ধরি নাম = "লিপি ২.০"
ধরি বয়স = ২
ধরি পাই = ৩.১৪১৫৯
ধরি সক্রিয় = সত্য

// ইংরেজি সিনট্যাক্স
title = "Lipi Sovereign"
count = 100
is_active = true

বলো "স্বাগতম: " + নাম
say "Status: " + is_active
```

লিপিতে খাঁটি বাংলা সংখ্যা (০, ১, ২, ৩, ৪, ৫, ৬, ৭, ৮, ৯) এবং রোমান সংখ্যা (0-9) সমানভাবে কাজ করে।

### শর্ত ও ব্রাঞ্চিং
```lipi
// বাংলা শৈলী
যদি বয়স >= ১৮
    বলো "প্রাপ্তবয়স্ক নাগরিক"
নাহলে_যদি বয়স >= ১৩
    বলো "কিশোর"
নাহলে
    বলো "শিশু"

// ইংরেজি শৈলী
if score >= 90
    say "Grade: A"
elif score >= 80
    say "Grade: B"
else
    say "Grade: C"
```

### লুপ ও পুনরাবৃত্তি
লিপিতে ৩ ধরনের লুপ রয়েছে:
1. `যতক্ষণ` / `while`
2. `প্রতিটি ... ভেতরে` / `for ... in`
3. `N বার বলো` / `repeat N`

```lipi
// ৫ বার পুনরাবৃত্তি
৫ বার বলো "জয় লিপি!"

repeat 3
    say "Repeating task..."

// রেঞ্জ লুপ
প্রতিটি i ভেতরে ১..৫
    বলো "বাংলা কাউন্টার: " + i

for i in 1..5
    say "English counter: " + i

// হোয়াইল লুপ
ধরি n = 3
যতক্ষণ n > 0
    বলো n
    n = n - 1
```

### ফাংশন ও কাজের সংজ্ঞা
ফাংশন ডিক্লেয়ার করার জন্য বাংলায় `কাজ` এবং ইংরেজিতে `fn` ব্যবহৃত হয়:

```lipi
// বাংলা সিনট্যাক্স
কাজ যোগ(ক, খ)
    ধরি ফলাফল = ক + খ
    ফেরত ফলাফল

// ইংরেজি মিনিমাল সিনট্যাক্স (স্পেস-সেপারেটেড প্যারামিটার)
fn multiply a b
    return a * b

বলো যোগ(১০, ২০)
say multiply(5, 6)
```

### কাস্টম গঠন ও টাইপ (Structs)
জটিল ডেটা মডেলিংয়ের জন্য `গঠন` বা `struct` ব্যবহার করা হয়:

```lipi
// বাংলা গঠন
গঠন ছাত্র
    নাম
    রোল
    বিভাগ

ধরি সাকিল = ছাত্র()
সাকিল.নাম = "সাকিল আহমেদ"
সাকিল.রোল = ১০১
সাকিল.বিভাগ = "কম্পিউটার সায়েন্স"

বলো সাকিল.নাম + " - " + সাকিল.বিভাগ
```

## ৪. সিস্টেম প্রোগ্রামিং ও লিনাক্স কার্নেল সিসকল
লিপি সরাসরি অপারেটিং সিস্টেম কার্নেলের সাথে সংযোগ স্থাপন করতে সক্ষম। `syscall(sys_no, arg1, arg2, arg3, arg4, arg5, arg6)` মেথড দিয়ে লিনাক্স x86_64 কার্নেলের প্রতিটি সার্ভিস সরাসরি ব্যবহার করা যায়:

```lipi
// কার্নেল সিসকল নম্বর (Linux x86_64)
// sys_write = 1, stdout = 1
msg = "লিপি সরাসরি লিনাক্স কার্নেলে লিখছে!\n"
syscall(1, 1, msg, len(msg))

// sys_getpid = 39
pid = syscall(39, 0, 0, 0)
say "Current Process ID: " + pid
```

## ৫. ডিরেক্ট ELF মেশিন কোড কম্পাইলার (`elf_emitter.lp`)
লিপির সবচেয়ে যুগান্তকারী উদ্ভাবন হলো `src/compiler/elf_emitter.lp`। এটি ১০০% খাঁটি লিপি ভাষায় লিখিত একটি মেশিন কোড কম্পাইলার যা:
- Lipi কোডের টোকেন ও AST তৈরি করে
- x86_64 মেশিন কোড ইনস্ট্রাকশন বাইট তৈরি করে (`push`, `pop`, `mov`, `lea`, `add`, `sub`, `syscall`, ইত্যাদি)
- লিনাক্স কার্নেলের জন্য রিয়েল-মোড ও মাল্টিবুট ১ মেমোরি লেআউট গঠন করে
- 64-বাইট ELF64 হেডার এবং Program হেডার তৈরি করে এক্সিকিউটেবল ফাইল রাইট করে।

ব্যবহার:
```bash
./bin/lipi src/compiler/elf_emitter.lp tests/01_hello.lp /tmp/native_out
chmod +x /tmp/native_out
/tmp/native_out
```

## ৬. প্যাকেজ ম্যানেজার (`lipipkg`) ব্যবহার নির্দেশিকা
লিপির জন্য ডেডিকেটেড প্যাকেজ ম্যানেজার `lipipkg`:

```bash
# নতুন প্রজেক্ট শুরু করা
lipipkg init my_app

# lipi.toml ফাইল কনফিগারেশন:
# [package]
# name = "my_app"
# version = "1.0.0"
#
# [dependencies]
# lipi-http = ">=1.0.0"

# প্রজেক্ট টেস্ট ও বিল্ড
lipipkg build
lipipkg test
```

## ৭. ভিজুয়াল স্টুডিও কোড (VS Code) ও LSP সেটআপ
লিপির অফিসিয়াল ভিএস কোড এক্সটেনশন `lipi-vscode/` ডিরেক্টরিতে প্রস্তুত:
- সম্পূর্ণ বাংলা ও ইংরেজি সিনট্যাক্স হাইলাইটিং (`lipi.tmLanguage.json`)
- স্বয়ংক্রিয় কোড স্নিপেট (`snippets/lipi.json`)
- ব্র্যাকেট ও ইন্ডেন্টেশন রুলস (`language-configuration.json`)
- বিল্টইন ল্যাঙ্গুয়েজ সার্ভার `bin/lipils`

ইনস্টলেশন:
```bash
cp -r lipi-vscode ~/.vscode/extensions/oshim.lipi-language-1.0.0
```
এরপর ভিএস কোড রিস্টার্ট করলেই যেকোনো `.lp` অথবা `.lipi` ফাইলে লিপির পূর্ণাঙ্গ এডিটিং সুবিধা পাওয়া যাবে।

## ৮. প্রোডাকশন অ্যাপ্লিকেশন ও ওয়েব সার্ভার
`apps/web_server/server.lp` ফাইলে লিপির সম্পূর্ণ প্রোডাকশন-গ্রেড HTTP ওয়েব ইঞ্জিন প্রদর্শিত হয়েছে। এটি রাউটিং, মিডলওয়্যার, JSON জেনারেশন এবং সিকিউরিটি গার্ড সমর্থন করে:

```bash
# রানার দিয়ে চালানো
./bin/lipi apps/web_server/server.lp

# নেটিভ কম্পাইল করে রান করা
./bin/lipc apps/web_server/server.lp -o bin/web_server
./bin/web_server
```

### উপসংহার
লিপি ভাষা এখন সম্পূর্ণ স্বনির্ভর, আধুনিক এবং বৈশ্বিক মানের। এটি শুধু ভাষার রূপান্তরের জন্য নয়, হার্ডওয়্যার লেভেল থেকে শুরু করে ক্লাউড ওয়েব সার্ভিস পর্যন্ত সম্পূর্ণ নির্ভরযোগ্যভাবে চলতে পারে।
