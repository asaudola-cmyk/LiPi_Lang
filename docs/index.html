Why Lipi?

Built for clarity. Built for everyone.

🚫

Zero Noise

No braces {}, no semicolons ;, no colons :. Just code that reads like plain English.

🌍

Unicode Identifiers

Variable and function names in ANY language — Bengali, Arabic, Chinese, Russian. English keywords, your language's words.

⚡

Instant Start

One-line install. No npm, no cargo, no SDK. Requires only Python 3.8+ which is already on most systems.

🔌

Independent

Install directly from GitHub. No PyPI. No package manager. Just curl | bash and you're running.

📚

Standard Library

math, http, json, fmt, io, str — all written in Lipi itself. Batteries included, all in .lp files.

🛠️

VS Code Extension

Syntax highlighting, snippets, and auto-indentation for .lp files. Works offline, no marketplace needed.

The Syntax

Minimal. Readable. Powerful.

Hello World
say "Hello, World!"
Variables
name    = "Lipi"
version = 2
active  = true
Functions
// One-liner
fn double n = n * 2

// Multi-line
fn factorial n
    if n <= 1
        return 1
    return n * factorial(n - 1)
Loops
for i in 1..10
    say i

while n > 0
    n = n - 1

repeat 5
    say "hello"
Structs
struct Point
    x
    y

p = Point()
p.x = 10
p.y = 20
say p.x + p.y    // 30
String Interpolation
name = "World"
say "Hello, {name}!"

lang = "Lipi"
ver  = 2
say "Welcome to {lang} {ver}.0!"

Unicode Identifiers

English keywords. Your language's words. Works everywhere.

// Bengali
নাম = "Lipi"
say নাম

// Bengali function
fn যোগফল a b = a + b
say যোগফল 10 20    // 30

// Multiple scripts work simultaneously
বাংলা    = "hello"    // Bengali
版本      = 2          // Chinese
اسم      = "world"   // Arabic
say বাংলা + " " + اسم

Install in 30 seconds

Requires: Python 3.8+ and git (both standard on Linux/macOS)

Step 1 — Install
$ curl -sSL https://raw.githubusercontent.com/asaudola-cmyk/LiPi_Lang/main/install.sh | bash
Step 2 — Restart terminal

Or run: source ~/.bashrc

Step 3 — Hello World
$ echo 'say "Hello, World!"' | lipi
Hello, World!
