# অধ্যায় ২: দ্বিভাষিক ও ত্রি-সিনট্যাক্স প্যারাডাইম (Bilingual & Tri-Syntax Paradigm)

> **"মাতৃভাষায় কোড লেখা কেবল আবেগ নয়, এটি চিন্তার স্বাধীনতা ও মেধার সর্বোচ্চ স্ফুরণ।"**

## ২.১ ত্রি-সিনট্যাক্স কাঠামো (The Tri-Syntax Architecture)
লিপি একই সাথে তিনটি সিনট্যাক্স শৈলী সমর্থন করে:
1. **বাংলা ক্যানোনিকাল (Bangla Canonical)**: সম্পূর্ণ বাংলায় প্রোগ্রামিং—যেখানে কি-ওয়ার্ড, চলক এবং ফাংশনের নাম খাঁটি বাংলা বর্ণমালায় লেখা যায়।
2. **ইংরেজি আধুনিক (English Modern)**: গ্লোবাল কমিউনিটির জন্য পাইথন ও রাস্টের মতো আধুনিক, পরিচ্ছন্ন সিনট্যাক্স।
3. **চিহ্ন ও ব্লক কাঠামো (Braced Block Style)**: পার্সিং স্তর স্বয়ংক্রিয়ভাবে ইন্ডেন্টেশন এবং ব্লককে সমন্বিত করে।

```
        ┌───────────────────────────────────────────────────────────┐
        │                 Lipi Lexer / Tokenizer                    │
        └─────────────────────────────┬─────────────────────────────┘
                                      │
              ┌───────────────────────┴───────────────────────┐
              ▼                                               ▼
    [Bangla Canonical AST]                          [English Modern AST]
    চলক ক = ১০                                      x = 10
    যদি ক > ৫:                                      if x > 5:
        বলো "বড়"                                        say "large"
              │                                               │
              └───────────────────────┬───────────────────────┘
                                      ▼
                       ┌─────────────────────────────┐
                       │     Unified Sovereign IR    │
                       └─────────────────────────────┘
```

## ২.২ কি-ওয়ার্ড ম্যাপিং টেবিল (Keyword Equivalence Matrix)

| বাংলা সিনট্যাক্স | ইংরেজি সমতুল্য | ব্যবহার ও উদ্দেশ্য |
|---|---|---|
| `ফাংশন` / `fn` | `fn` / `function` | নতুন ফাংশন সংজ্ঞায়িত করা |
| `যদি` | `if` | শর্তাধীন ব্রাঞ্চিং |
| `নতুবা_যদি` | `elif` | বিকল্প শর্তাধীন ব্রাঞ্চিং |
| `নতুবা` | `else` | অন্যথায় ডিফল্ট ব্রাঞ্চ |
| `যতক্ষণ` | `while` | শর্তাধীন লুপ |
| `জন্য` | `for` | রেঞ্জ বা ইটারেশন লুপ |
| `ফেরত` | `return` | ফাংশন থেকে মান প্রত্যাবর্তন |
| `বলো` | `say` | কনসোলে বার্তা মুদ্রণ (sys_write) |
| `অন্তর্ভুক্ত` | `include` | অন্য ফাইল বা মডিউল যুক্ত করা |

## ২.৩ দ্বিভাষিক কোডের বাস্তব উদাহরণ (Bilingual Working Example)

নিচের কোডটি বাংলায় লিখুন `factorial_bn.lp`:

```lipi
// দ্বিভাষিক লিপিতে ফ্যাক্টোরিয়াল গণনা
fn ফ্যাক্টোরিয়াল সংখ্যা
    যদি সংখ্যা <= 1
        ফেরত 1
    নতুবা
        ফেরত সংখ্যা * ফ্যাক্টোরিয়াল(সংখ্যা - 1)

fn main
    ফলাফল = ফ্যাক্টোরিয়াল(5)
    বলো "৫ এর ফ্যাক্টোরিয়াল: " + to_str(ফলাফল)
    return 0

main()
```

লিপি কম্পাইলার কোনো রকম বাহ্যিক কনভার্টার ছাড়াই সরাসরি এই বাংলা টোকেনগুলোকে প্রসেস করে নেটিভ x86_64 মেশিন কোডে রূপান্তরিত করে।
