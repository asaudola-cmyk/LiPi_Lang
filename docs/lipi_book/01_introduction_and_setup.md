# অধ্যায় ১: পরিচিতি ও সার্বভৌম পরিবেশ প্রস্তুতি (Introduction & Sovereign Setup)

> **"কম্পাইলারের প্রতিটি বাইট যদি তোমার নিজের না হয়, তবে তোমার সিস্টেম কখনো তোমার নয়।"**

---

## ১.১ সার্বভৌম প্রযুক্তির দর্শন (The Philosophy of Sovereignty)
আধুনিক সফটওয়্যার ইঞ্জিনিয়ারিংয়ের প্রায় পুরো ইকোসিস্টেম শত শত থার্ড-পার্টি ডিপেন্ডেন্সির এক জটিল জালে আবদ্ধ। একটি সাধারণ হ্যালো-ওয়ার্ল্ড বাইনারি তৈরি করতেও সি রানটাইম (`libc.so`), ডায়নামিক লিঙ্কার (`ld-linux.so`), এবং শত শত মেগাবাইট আকারের সি কম্পাইলার টুলচেইনের প্রয়োজন পড়ে।

লিপি (Lipi) এই নির্ভরশীলতার প্রাচীর ভেঙে গুঁড়িয়ে দিয়েছে। 
- **০% C / GCC নির্ভরতা**: কোনো সি কম্পাইলার প্রয়োজন নেই।
- **০% Libc নির্ভরতা**: মেমরি ম্যানেজমেন্ট, আই/ও এবং প্রসেস ম্যানেজমেন্ট সরাসরি লিনাক্স সিসকল ইন্টারফেস (`syscall`) দিয়ে সম্পন্ন হয়।
- **০% পাইথন বা পিএইচপি নির্ভরতা**: লিপি তার নিজস্ব বুটস্ট্র্যাপ সিড (`boot/lipi-seed`) থেকে স্বয়ংসম্পূর্ণভাবে ৩ প্রজন্মের স্ব-হোস্টিং ক্লাস্টার (`Gen1 -> Gen2 -> Gen3`) দিয়ে নিজেকে পুনর্নির্মাণ করে।

```
                               ┌─────────────────────────┐
                               │     boot/lipi-seed      │  (Gen0 Seed: 100% Static ELF)
                               └────────────┬────────────┘
                                            ▼
                               ┌─────────────────────────┐
                               │      bin/lipc_gen1      │  (Compiles Lipi Source)
                               └────────────┬────────────┘
                                            ▼
                               ┌─────────────────────────┐
                               │      bin/lipc_gen2      │  (Optimized Self-Host)
                               └────────────┬────────────┘
                                            ▼
                               ┌─────────────────────────┐
                               │      bin/lipc_gen3      │  (Bit-for-Bit Deterministic Closure)
                               └─────────────────────────┘
                                     Gen2 == Gen3 (diff = 0)
```

## ১.২ বুটস্ট্র্যাপ পাইপলাইন ও পরিবেশ প্রস্তুতি (Bootstrap Pipeline)
লিপি কোডবেস বিল্ড করার জন্য শুধুমাত্র একটি স্ট্যান্ডার্ড লিনাক্স শেল প্রয়োজন:

```bash
# ১. রিপোজিটরি ক্লোন বা ফোল্ডারে প্রবেশ
cd lipi/

# ২. সম্পূর্ণ সার্বভৌম বিল্ড পাইপলাইন চালনা
./build.sh
```

বিল্ড স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে নিচের ধাপগুলো সম্পন্ন করে:
1. `boot/lipi-seed` থেকে প্রথম প্রজন্মের কম্পাইলার তৈরি করে।
2. নতুন কোডবেস থেকে দ্বিতীয় প্রজন্মের কম্পাইলার তৈরি করে।
3. দ্বিতীয় প্রজন্মের কম্পাইলার দিয়ে তৃতীয় প্রজন্মের কম্পাইলার তৈরি করে এবং বাইট-টু-বাইট তুলনা (`cmp -s`) করে নিশ্চিত করে যে কম্পাইলারটি ১০০% ডিটারমিনিস্টিক।
4. সম্পূর্ণ রিগ্রেশন টেস্ট স্যুট (১০৪+ টেস্ট) সরাসরি মেশিন কোড মোডে এক্সিকিউট করে।

## ১.৩ প্রথম সার্বভৌম লিপি প্রোগ্রাম (First Sovereign Lipi Program)
একটি নতুন ফাইল তৈরি করুন `hello.lp`:

```lipi
// প্রথম সার্বভৌম লিপি প্রোগ্রাম
fn main
    say "নমস্কার, বিশ্ব! সার্বভৌম লিপির জগতে স্বাগতম।"
    say "Hello, World! 100% Native Pure Lipi Machine Code."
    return 0

main()
```

কম্পাইল এবং রান করুন:
```bash
bin/lipc hello.lp -o hello
./hello
```

কোনো লাইব্রেরি বা নির্ভরতা ছাড়াই তৈরি হওয়া এক্সিকিউটেবলটি সরাসরি ওএসের রিং-৩ মোডে এক্সিকিউট হবে। আপনি `readelf -l hello` দিয়ে পরীক্ষা করে দেখতে পারেন—এটি একটি ১০০% স্ট্যান্ডঅ্যালোন স্ট্যাটিক ELF64 বাইনারি!
