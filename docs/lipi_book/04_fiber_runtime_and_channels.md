# অধ্যায় ৪: ফাইবার রানটাইম ও সিএসপি চ্যানেল (Fiber Runtime & CSP Channels)

> **"ওএস থ্রেডের ভারী কন্টেক্সট সুইচিং ভুলে যাও; হালকা ফাইবারে গড়ে তোলো লাখো সমান্তরাল ধারা।"**

---

## ৪.১ ওএস থ্রেড বনাম লিপি ফাইবার (Threads vs Sovereign Fibers)
প্রথাগত ওএস থ্রেডের প্রতিটি তৈরি হতে ২ থেকে ৮ মেগাবাইট মেমরি খরচ হয় এবং তাদের শিডিউল করতে ওএস কার্নেল রিং-০ মোডে কন্টেক্সট সুইচ করে, যা হাজার হাজার রিকোয়েস্টে সিপিইউ ক্যাশ ধ্বংস করে দেয়।

লিপির **ফাইবার রানটাইম (Fiber Runtime)**:
- প্রতিটি ফাইবার মাত্র কয়েক কিলোবাইটের নিজস্ব ইউজার-স্পেস স্ট্যাক নিয়ে চলে।
- কন্টেক্সট সুইচিং ঘটে মাত্র ১০ থেকে ১৫টি সিপিইউ ইনস্ট্রাকশনে (`push/pop` এবং `rsp` সোয়াপ)।
- একক ওএস থ্রেডে একসাথে লাখ লাখ ফাইবার সমান্তরালে চলতে পারে।

```
    OS Thread (Kernel Space Context Switch: 2000+ Cycles)
    ─────────────────────────────────────────────────────────────
    Pure Lipi Fiber Scheduler (User Space Switch: ~15 Cycles)
    ┌──────────┐      ┌──────────┐      ┌──────────┐
    │ Fiber #1 │ ───► │ Fiber #2 │ ───► │ Fiber #3 │ ───► ...
    │ State    │      │ State    │      │ State    │
    └──────────┘      └──────────┘      └──────────┘
             ▲                                ▲
             └────────── [ Channel ] ─────────┘
                    (Lock-Free Ring Buffer)
```

## ৪.২ সিএসপি চ্যানেল ভিত্তিক যোগাযোগ (Communicating Sequential Processes)
লিপিতে ফাইবারগুলোর মধ্যে ডেটা বিনিময়ের জন্য কোনো মিউটেক্স (Mutex) লক বা ডেডলক-প্রবণ গ্লোবাল ভেরিয়েবল প্রয়োজন নেই। লিপি টনি হোরের CSP মডেল অনুসরণ করে লক-ফ্রি চ্যানেলের মাধ্যমে বার্তা আদান-প্রদান করে।

```lipi
include "universe/core/concurrency.lp"

fn worker_task chan_in chan_out
    // চ্যানেল থেকে বার্তা গ্রহণ
    msg = chan_recv(chan_in)
    say "ফাইবার কর্মী বার্তা পেল: " + msg

    // প্রসেস করে নতুন বার্তা পাঠানো
    res = msg + " [প্রসেসড]"
    chan_send(chan_out, res)
    return 0

fn main
    ch1 = chan_new(10)
    ch2 = chan_new(10)

    chan_send(ch1, "টাস্ক ১")
    worker_task(ch1, ch2)

    final_msg = chan_recv(ch2)
    say "চূড়ান্ত ফলাফল: " + final_msg
    return 0

main()
```
