# অধ্যায় ৯: ক্রিপ্টোগ্রাফিক স্যুট ও লিপিপ্যাকেজ হাব (Cryptographic Suite & LipiPkg Hub)

## ৯.১ খাঁটি লিপি ক্রিপ্টোগ্রাফি (Pure Lipi TLS 1.3 & AES-GCM)
লিপি ওপেনএসএসএল (OpenSSL) বা কোনো সি ক্রিপ্টো লাইব্রেরির ওপর নির্ভর করে না। লিপির স্ট্যান্ডার্ড লাইব্রেরিতে অন্তর্ভুক্ত রয়েছে গাণিতিকভাবে নির্ভুল খাঁটি ক্রিপ্টো ইঞ্জিন:
- **AES-128 / AES-256 (NIST SP 800-38D)**: এস-বক্স সাবস্টিটিউশন, শিফট-রোজ, মিক্স-কলামস এবং জিহ্যাশ (GHASH) পলিনোমিয়াল অথেন্টিকেশন ট্যাগ।
- **SHA-256 ও SHA-512**: ক্রিপ্টোগ্রাফিক হ্যাশিং ও ডাটা ইনটিগ্রিটি।
- **TLS 1.3 রেকর্ড লেয়ার**: এন্ড-টু-এন্ড এনক্রিপ্টেড নেটওয়ার্ক সকেট।

```
    Plaintext Message + Dynamic Key + IV + AAD
                        │
                        ▼
    Lipi Pure AES-GCM Core (Galois/Counter Mode)
                        │
            ┌───────────┴───────────┐
            ▼                       ▼
    Ciphertext Payload     128-bit GHASH Auth Tag
            │                       │
            └───────────┬───────────┘
                        ▼
    Tamper-Proof Authenticated TLS 1.3 Record Frame
```

## ৯.২ লিপিপ্যাকেজ ও ডিটারমিনিস্টিক লকফাইল (LipiPkg & Deterministic Hub)
লিপিপ্যাকেজ (`universe/pkg/lipipkg_hub.lp`) একটি সম্পূর্ণ সার্বভৌম ও বিকেন্দ্রীভূত প্যাকেজ ম্যানেজার:
- **ডিপেনডেন্সি ক্রিপ্টোগ্রাফিক হ্যাশিং**: প্রতিটি মডিউলের বিষয়বস্তু SHA-256 দিয়ে যাচাইকৃত।
- **ডিটারমিনিস্টিক লকফাইল (`lipipkg.lock`)**: পৃথিবীর যেকোনো কম্পিউটারে একই ডিপেনডেন্সি ট্রি থেকে হুবহু একই বাইনারি তৈরি নিশ্চিত করে।

```lipi
include "universe/crypto/crypto.lp"

fn main
    বার্তা = "abc"
    হ্যাশ = sha256_hex(বার্তা)
    say "মেসেজ ডাইজেস্ট (SHA-256): " + হ্যাশ
    return 0

main()
```
